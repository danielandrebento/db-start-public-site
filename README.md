# DB Start public site

Site estático bilingue PT-PT/EN pronto para alojamento numa origem HTTPS estável. Não usa JavaScript, cookies, analytics ou backend.

Ficheiros principais:
- `index.html` — apresentação pública.
- `privacy.html` — Política de Privacidade integral PT-PT + EN.
- `support.html` — suporte PT-PT + EN.
- `style.css` — estilos locais.
- `_headers` — cabeçalhos de segurança para hosts compatíveis.
- `robots.txt` — indexação pública.
- `DEPLOYMENT.md` — instruções de alojamento.

Depois de publicar, registar os URLs finais em `docs/STORE_SUBMISSION_PACK.md` e `docs/PUBLIC_RELEASE_CHECKLIST.md`. Não inventar URLs antes do alojamento estar ativo.
