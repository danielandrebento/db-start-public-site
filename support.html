Suporte

Para questões, erros, dúvidas de utilização ou privacidade, escreve para dbstart-by-emt@pm.me.

Ao pedir ajuda, indica a versão do DB Start, o browser e uma descrição curta do problema. Não envies palavras-passe, tokens, chaves API, ficheiros de configuração completos ou outros dados sensíveis.

Support

For questions, bugs, usage issues or privacy requests, contact dbstart-by-emt@pm.me.

Include the DB Start version, browser and a short description of the issue. Do not send passwords, tokens, API keys, full configuration exports or other sensitive data.

Integração local / Local integration

O DB Start Launcher é opcional e separado da extensão. A extensão continua funcional para sites sem o launcher.

DB Start Launcher is optional and separate from the extension. Web shortcuts continue to work without it.
